# Устранение неполадок

## ADB / эмулятор

1. На вкладке **Обзор** выберите правильный эмулятор и нажмите **Запустить проверки**.
2. **LDPlayer:** Настройки → Другие настройки → включите отладку ADB, перезапустите эмулятор. Порт **5555** (экземпляр 1: **5557**).
3. **MuMu:** убедитесь, что ADB включён. Порт **16384** (экземпляр 1: **16416**).
4. Если видны два устройства (`127.0.0.1:5555` + `emulator-5554`), перезапустите ADB эмулятора или переподключитесь с вкладки **Обзор**.

## Низкий IPS

1. Выполните `python tools/performance_check.py`.
2. Если провайдер — CPU, снова запустите `setup.cmd` или установите `cpu_or_gpu = "directml"` в `cfg/general_config.toml`.
3. Установите эмулятор на 1920×1080, 60 FPS, отключите эко-режимы и низкий FPS.
4. ~60 IPS — норма при `scrcpy_max_fps = 60`.

## Пустой список в режиме нескольких экземпляров

Откройте **Экземпляры**, включите несколько экземпляров, нажмите **Обновить**. Каждому экземпляру нужен план фарма в `instances/<id>/latest_brawler_data.json`.

## Частое срабатывание восстановления

Прочитайте **Журнал восстановления** на **Обзоре** и `logs/recovery_events.jsonl`. Увеличьте пороги низкого IPS на вкладке **Таймеры**, если восстановление срабатывает слишком часто.

## GPU / DirectML

На ноутбуках с гибридной графикой в параметрах графики Windows для Python и эмулятора выберите **Высокая производительность**. Попробуйте `directml_device_id = "1"`, если устройство 0 работает медленно.
