# Несколько экземпляров

Запускайте несколько ботов LDPlayer или MuMu параллельно с вкладки **Экземпляры** в Hub.

## Включение

1. Откройте **Экземпляры**.
2. Включите **Включить несколько экземпляров**.
3. Следуйте панели **Быстрая настройка** (сканирование эмуляторов, быстрое добавление неназначенных).
4. Перезапустите Hub, если удалённое управление Discord/Telegram не видит экземпляры.

## Добавление экземпляров

**Простой путь**

1. Нажмите **Сканировать эмуляторы** или **Добавить все неназначенные**.
2. Каждый обнаруженный эмулятор станет экземпляром с уникальным портом и копией плана фарма Default.

**Ручной путь**

1. Нажмите **Добавить вручную**, выберите обнаруженный эмулятор кнопкой **Выбрать** или разверните **Расширенные**, чтобы задать порт вручную.
2. При необходимости укажите тег игрока для автозаполнения кубков через API.

## План фарма для каждого экземпляра

1. Откройте **План фарма**.
2. Используйте переключатель экземпляра вверху (**Редактирование плана фарма для**).
3. Соберите или импортируйте очередь для этого экземпляра.

Каждый экземпляр автоматически сохраняет план в `instances/<id>/latest_brawler_data.json` — пути вручную редактировать не нужно.

## Запуск воркеров

1. Нажмите **Запуск** у каждого готового экземпляра или **Запустить все готовые**.
2. Нажмите **Выровнять окна**, чтобы расположить окна эмуляторов.
3. **Не** используйте **СТАРТ** на вкладке **Обзор** в режиме нескольких экземпляров.

## Удалённое управление

Один бот Discord/Telegram в Hub управляет всеми экземплярами:

- Discord: `/status instance:ld-2`
- Telegram: `/status ld-2` (третий аргумент)

## Уведомления о матчах для каждого экземпляра (необязательно)

На карточке каждого экземпляра укажите URL вебхука и ID для пинга при оповещениях о матчах. Команды управления по-прежнему настраиваются на глобальных вкладках Discord/Telegram.
