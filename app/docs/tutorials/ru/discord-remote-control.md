# Удалённое управление Discord

Управляйте запущенным ботом Pyla-RL из Discord с помощью слэш-команд. Это отдельно от уведомлений через вебхук.

## Безопасность

- Включайте удалённое управление только для **вашего** Discord user ID и **вашего** канала команд.
- Никому не передавайте токен бота.
- Используйте приватный админ-канал для `/screenshot`.

## Настройка

1. Создайте бота на https://discord.com/developers/applications
2. Скопируйте токен бота на вкладку **Discord** в Hub (`discord_bot_token`).
3. Пригласите бота с правами `bot` и `applications.commands`.
4. Включите режим разработчика в Discord и скопируйте:
   - Ваш user ID → `discord_control_user_id`
   - ID канала команд → `discord_control_channel_id`
   - ID сервера → `discord_control_guild_id` (быстрее синхронизация слэш-команд)
5. Установите `discord_control_enabled = true` и перезапустите Pyla-RL.

## Справочник команд

| Команда | Описание |
|---------|----------|
| `/start` | Возобновить бота |
| `/pause` | Приостановить бота (`/stop` устарел) |
| `/status` | Текущее состояние, IPS, бравлер, цель |
| `/stats` | Победы/поражения/время работы сессии |
| `/queue` | Показать план фарма |
| `/push` | Приоритет бравлера |
| `/skip` | Следующий бравлер в очереди |
| `/remove` | Удалить бравлера из очереди |
| `/target` | Задать цель по кубкам для активного бравлера |
| `/screenshot` | Отправить скриншот эмулятора |
| `/restart_game` | Перезапустить Brawl Stars и scrcpy |
| `/restart_scrcpy` | Перезапустить только видеопоток |
| `/restart_emulator` | Перезапустить профиль эмулятора |
| `/back` | Android Back |
| `/press` | Нажать q/e/f/g/h/m/back |
| `/help` | Список команд |

## Несколько экземпляров

Добавьте `instance:your-id` к командам, например `/status instance:ld-2`.

## Порядок восстановления

1. `/back` — для меню
2. `/restart_scrcpy` — при зависшем потоке
3. `/restart_game` — при сбое игры
4. `/restart_emulator` — при зависшем эмуляторе/ADB

## Устранение неполадок

- **Команды не отображаются:** перезапустите Pyla-RL, проверьте guild ID и права приглашения бота.
- **Доступ запрещён:** проверьте user ID, channel ID и guild ID.
- **Скриншот не удаётся:** сначала выполните `/status`, затем попробуйте `/restart_scrcpy`.
