# Уведомления Discord

## Вебхук (только уведомления)

1. Откройте вкладку **Discord** или `cfg/discord_config.toml`.
2. Вставьте **URL вебхука** канала.
3. Включите **Отправлять сводку матча**, чтобы публиковать отчёт после каждой завершённой игры.
4. Установите **Пинг каждые X матчей** в `1`, если нужен `@mention` в каждой сводке (`0` = сводки без упоминания).

Сводки матчей включают бравлера, результат, изменение кубков и при необходимости скриншот.

**Пульс каждые X минут** — необязательно. Оставьте `0`, если не нужен отдельный пинг «ещё работает». Он не заменяет сводки матчей.

Вебхуки не могут принимать команды.

## Удалённое управление (необязательно)

Для слэш-команд нужен **токен бота** и ограниченные ID пользователя/канала.

Полная настройка — в разделе [Удалённое управление Discord](discord-remote-control.md).

## Перезапуск

Перезапустите Pyla-RL после изменения настроек Discord.
