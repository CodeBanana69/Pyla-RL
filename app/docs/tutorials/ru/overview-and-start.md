# Обзор и СТАРТ

## Предстартовые проверки

На вкладке **Обзор**:

1. Выберите **LDPlayer** или **MuMu**.
2. Нажмите **Запустить проверки** или **Проверить соединение**.
3. Устраните **обязательные** ошибки (обычно ADB) перед СТАРТ.

| Проверка | Обязательна? |
|----------|--------------|
| Устройство ADB | Да |
| Процесс эмулятора | Рекомендуется |
| Brawl Stars на переднем плане | Рекомендуется |
| Разрешение 1080p | Рекомендуется |

## Режим игры

**Showdown Trio** — основной настроенный режим в этом форке. **Brawl Ball** также доступен в Hub и использует `playstyles/default.pyla`.

## Профиль производительности

На вкладке **Обзор** выберите **Сбалансированный**, **Слабый ПК** или другой профиль. Перезапустите бота после смены профиля.

## СТАРТ

- **Один экземпляр:** нажмите **СТАРТ** на вкладке **Обзор** после успешных проверок.
- **Несколько экземпляров:** включите режим на вкладке **Экземпляры**, соберите план фарма для каждого экземпляра, затем нажмите **Запуск** у каждого воркера (СТАРТ на **Обзоре** отключён).

## Обновления

В заголовке Hub рядом с переключателем языка (EN/RU) отображается **индикатор обновлений**. Он сравнивает установленный коммит ветки `main` с GitHub и открывает всплывающее окно с:

- установленной версией и локальным/последним SHA коммита;
- **Запустить обновление** (запускает `update.cmd`, если он есть);
- **Обновить** статус.

Если индикатор сообщает о доступном обновлении, используйте `update.exe` / `update.cmd` из папки установки.

## Во время работы

Окно **Pyla-RL Control** позволяет безопасно приостанавливать и возобновлять работу (**F8**). В нём отображаются индикатор состояния (работает/пауза), кнопка паузы на всю ширину, график IPS и полоска сессии (нажмите, чтобы скопировать). Используйте **Открыть Hub** или компактную панель, если окно мешает.
