# История матчей

## Просмотр истории

Вкладка **История матчей** показывает недавние матчи и сводную статистику для текущего файла данных.

## Сортировка

Используйте элемент сортировки, чтобы упорядочить по количеству игр, имени бравлера или проценту побед.

## Сброс

Нажмите **Сбросить статистику**, чтобы очистить сохранённую историю матчей (подтвердите действие).

## Удалённая статистика

Discord `/stats` и Telegram `/stats` показывают статистику текущей сессии в реальном времени, пока бот работает.
