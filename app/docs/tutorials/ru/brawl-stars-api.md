# API Brawl Stars

## Настройка

1. Создайте аккаунт разработчика на https://developer.brawlstars.com/
2. Откройте вкладку **API** или `cfg/brawl_stars_api.toml`.
3. Заполните:
   - `player_tag`
   - `developer_email`
   - `developer_password`

## Что это даёт

- **Автозаполнение кубков** при выборе бравлеров
- **ВСЕ НА ПУШ / Собрать очередь** на вкладке **План фарма**
- Автообновление ключа для текущего публичного IP

## Безопасность

- Оставьте `delete_all_tokens = false`, если не планируете удалить все ключи на аккаунте.
- Не коммитьте заполненные учётные данные в GitHub.

## Процесс «ВСЕ НА ПУШ»

1. Настройте учётные данные API.
2. Откройте Brawl Stars в лобби эмулятора.
3. На вкладке **План фарма** задайте цель по кубкам и нажмите **Собрать очередь**.

Добавляются только бравлеры ниже цели (по данным API).
