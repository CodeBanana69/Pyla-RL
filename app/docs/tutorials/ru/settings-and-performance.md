# Настройки и производительность

## Лицензия

Примите лицензию свободного использования в **Настройки → О программе** перед СТАРТ.

Pyla-RL бесплатен и с открытым исходным кодом (CC BY-NC 4.0). Не продавайте и не перепродавайте его.

## Папка cfg

**Открыть папку cfg** открывает `cfg/` для расширенного редактирования TOML. Перезапустите бота после изменений.

### Где хранятся настройки

| Уровень | Путь | Назначение |
|---------|------|------------|
| Стандартные значения | `cfg/*.toml` | Версионируемые шаблоны в репозитории |
| Секреты машины | `cfg/*.local.toml` | Токены API, токен бота Telegram (в .gitignore) |
| Среда выполнения бота | `instances/<id>/` | JSON плана фарма и переопределения экземпляра |

Полная карта папок — в [REPO_LAYOUT.md](../REPO_LAYOUT.md).

Примечание: `cfg/time_tresholds.toml` сохраняет устаревшее написание имени файла; не переименовывайте его без миграционного шима.

## Профиль производительности

Профили на вкладке **Обзор** настраивают захват scrcpy, потоки ONNX и связанные параметры среды выполнения.

Выполните `python tools/performance_check.py`, чтобы диагностировать низкий IPS или неверный GPU-провайдер.

## Вывод в терминал

**Настройки → Терминал / отладка** управляет объёмом вывода в консоль:

| Параметр | По умолчанию | Назначение |
|----------|--------------|------------|
| Подробность терминала | `normal` | `quiet`, `normal`, `verbose` или `debug` |
| Строка статуса в консоли | вкл. | Обновляет IPS на месте вместо новой строки каждую секунду |
| Интервал сводки статуса (сек) | `5` | Как часто строка статуса также показывает состояние и активного бравлера |
| Отладка движения | выкл. | Ограниченный трейс движения (независимо от экрана отладки) |
| Экран отладки | выкл. | Только визуальный оверлей; не засоряет терминал |
| Сохранять лог терминала | выкл. | Дублирует stdout/stderr в файлы с метками времени в `logs/` |
| Отладка застревания у стен | выкл. | Диагностика движения при выходе из застревания |

Рекомендуемая повседневная настройка: **Подробность терминала = normal**, **Строка статуса в консоли = вкл.**, **Экран отладки** — только когда нужен оверлей.

## Параметры отладки

Можно включить **Отладку супера** для диагностики по количеству пикселей и более глубоких трейсов зрения. Это отдельно от обычных уровней подробности терминала.

## Повторный показ мастера настройки

**Настройки → О программе → Показать мастер настройки снова** снова открывает мастер первого запуска.
