# Таймеры и восстановление

## Восстановление при низком IPS

Когда скорость обработки изображений (IPS) остаётся низкой, Pyla-RL может автоматически:

1. Перезапустить поток scrcpy
2. Перезапустить Brawl Stars
3. Перезапустить профиль эмулятора

Настройте пороги на вкладке **Таймеры**:

- **Восстановление при низком IPS (сек)** — как долго IPS должен оставаться низким
- **Кулдаун низкого IPS** — минимальный интервал между попытками восстановления
- **Попытка перезапуска приложения** — после N попыток перезапустить игру
- **Попытка перезапуска эмулятора** — после N попыток перезапустить эмулятор

## Другие таймеры

На вкладке **Таймеры** также настраиваются задержки меню, кулдауны перезапуска эмулятора и связанные значения сторожевых таймеров.

## Журнал восстановления

На вкладке **Обзор** нажмите **Журнал восстановления**, чтобы просмотреть недавние события автовосстановления из `logs/recovery_events.jsonl`.

## Встроенное восстановление (без настройки)

Pyla-RL также обрабатывает:

- Brawl Stars закрыт или другое приложение на переднем плане → перезапуск игры
- Диалог отключения из-за простоя → нажатие Reload
- Зависший поток scrcpy → перезапуск потока
