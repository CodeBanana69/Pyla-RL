# План фарма

## Сборка очереди

1. Откройте вкладку **План фарма**.
2. Нажмите **Добавить**, чтобы выбрать бравлера и цель по кубкам.
3. Или используйте **Собрать очередь** (**ВСЕ НА ПУШ**) после настройки вкладки **API**.

## Порядок

- Перетащите строку за ручку, чтобы изменить порядок.
- **Первый** бравлер в списке активен при запуске бота.

## Импорт / экспорт

- **Экспорт** сохраняет очередь в JSON для резервной копии.
- **Импорт** загружает сохранённый файл очереди.

## Пустая очередь

Если план фарма пуст, при СТАРТ откроется окно классического выбора бравлера.

## Формат файла очереди

В режиме одного экземпляра используется `data/latest_brawler_data.json` в папке проекта.

Пример записи:

```json
{
  "brawler": "shelly",
  "push_until": 1000,
  "trophies": 0,
  "type": "trophies",
  "automatically_pick": true,
  "selection_method": "named_brawler"
}
```

Пути очередей для каждого экземпляра — в разделе [Несколько экземпляров](multi-instance.md).
