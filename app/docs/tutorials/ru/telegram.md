# Telegram

## Уведомления

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. Вставьте токен на вкладке **Telegram** (`bot_token`).
3. Установите `enabled = true`.
4. Отправьте боту `/setup`, чтобы зарегистрировать чат.

## Команды удалённого управления

Отправьте боту:

| Команда | Описание |
|---------|----------|
| `/status` | Состояние бота и метрики |
| `/stats` | Статистика сессии |
| `/pause` | Приостановить движение |
| `/resume` | Возобновить |
| `/queue` | Предпросмотр плана фарма |
| `/push` | Приоритет бравлера |
| `/skip` | Следующий бравлер |
| `/remove` | Удалить из очереди |
| `/target` | Задать цель по кубкам |
| `/screenshot` | Скриншот эмулятора |
| `/restart_game` | Перезапустить игру |
| `/restart_scrcpy` | Перезапустить поток |
| `/restart_emulator` | Перезапустить эмулятор |
| `/back` | Android Back |
| `/press` | Кнопка в игре |
| `/help` | Список команд |

## Несколько экземпляров

Добавьте ID экземпляра дополнительным аргументом, например `/push shelly 1000 ld-2`.

## Перезапуск

Перезапустите Pyla-RL после изменения настроек Telegram.
